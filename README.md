# RetroMail：经典 Mac OS 风格的 iOS 邮件客户端

黑白 1-bit 界面：条纹标题栏、关闭框、网点桌面、双线框对话框、"文件 / 邮箱 / 特别" 菜单栏。
标准 IMAP + SMTP，适用于企业邮箱和任何自定义服务器。

## 功能

- **账户**：多账户；可以手动填写 IMAP/SMTP 服务器，也可以一键套用预设（腾讯企业邮、阿里企业邮、网易企业邮、QQ、163、Gmail）；支持 SSL/TLS、STARTTLS、不加密三种连接方式；收件和发件可以用不同的账号密码；可以允许自签名证书（适合公司内网）；有“测试连接”按钮；密码保存在系统钥匙串。
- **收件**：显示文件夹树和未读数，能自动识别中英文的已发送、草稿、已删除等文件夹；下拉刷新；滚动到底部自动加载更早的邮件；离线缓存列表和已读过的邮件。
- **阅读**：HTML 和纯文本正文；默认拦截远程图片（防止发件人追踪），点一下可以显示；内嵌图片 (cid) 正常显示；附件可以预览和分享（PDF、Office、图片等，用系统 QuickLook）；`mailto:` 链接会直接打开写信界面。
- **字符集**：UTF-8、GBK、GB2312、GB18030、Big5 等；支持 RFC 2047 编码的标题和 RFC 2231 编码的中文附件名。
- **管理邮件**：已读/未读、旗标、移动到其他文件夹、删除（移到“已删除”）；左右滑动做快捷操作；多选后批量处理；在服务器端搜索主题、发件人、收件人。
- **写信**：新邮件、回复、全部回复、转发（原附件一起带上）；抄送和密送；从相册或“文件”添加附件（HEIC 照片会自动转成 JPG）；签名；保存草稿、继续编辑草稿；发出后保存到“已发送”。
- **通知**：可以开启后台检查新邮件并发出本地通知。检查频率由 iOS 决定。

## 怎样得到 .ipa（不需要 Mac）

iOS 应用只能在 macOS + Xcode 上编译，所以这里借用 GitHub 提供的免费 macOS 云主机来编译。

1. 登录 GitHub，新建一个仓库（Public 或 Private 都可以）。
2. 把压缩包解压后 `RetroMail` 文件夹**里面的全部内容**上传到仓库根目录（即 `project.yml` 要在仓库最外层），包括 `.github` 文件夹（它在 macOS 上默认隐藏，Windows 上能直接看到）。
   - 网页上传：仓库页面 → **Add file → Upload files**，把文件和文件夹拖进去后提交。
   - 也可以用 GitHub Desktop 或 `git push`。
3. 打开仓库的 **Actions** 标签。上传完成后会自动开始编译，大约需要 5–10 分钟；也可以手动点 **Build IPA → Run workflow**。
4. 编译成功后，打开这次运行的页面，在最下方 **Artifacts** 里下载 `RetroMail-ipa`。下载到的是一个 zip，解压后就是 `RetroMail.ipa`。
5. 用你常用的自签工具（Sideloadly、AltStore、轻松签、爱思助手等）签名安装。Bundle ID 是 `com.raynec.retromail`，需要的话可以在签名工具里改。

> 私有仓库每月有免费的 Actions 时长，macOS 主机按 10 倍计算，大概够编译二三十次。公开仓库不限时长。

## 首次使用

1. 点“添加账户…”，填写显示名称、邮箱地址和密码。服务器地址会根据邮箱域名自动猜测，猜错了可以手动改，也可以点“套用常见服务器 ▾”。
2. 点 **测试连接**，确认收件和发件都显示 ✓，再点 **存储**。
3. 企业邮箱需要管理员在后台开启 IMAP/SMTP 服务。开启了“安全登录”或微信动态码的邮箱，要使用**客户端专用密码**。

## 已知限制

- 不支持 Microsoft 365 / Exchange Online 的 OAuth 登录。微软已经关闭了这类邮箱的密码登录 IMAP；公司自建的 Exchange 如果开启了 IMAP，可以正常使用。
- 新邮件提醒依靠 iOS 后台刷新，没有服务器推送，所以会有延迟。
- 写信只支持纯文本，不支持富文本编辑；收到的 HTML 邮件可以正常显示。
- 打开一封邮件时会下载整封邮件（包括附件），之后会缓存在本机。

## 项目结构

```
project.yml                 XcodeGen 工程描述（云端生成 .xcodeproj）
.github/workflows/build.yml 云端编译并打包未签名 ipa
RetroMail/Core              网络与协议：TLS 套接字、IMAP、SMTP、MIME 解析与生成
RetroMail/Models            账户、钥匙串、缓存、全局邮件服务、后台刷新
RetroMail/UI                经典 Mac OS 风格界面组件与各页面
```

没有任何第三方依赖，只使用 Apple 系统框架（SwiftUI、Foundation、WebKit、QuickLook、PhotosUI、BackgroundTasks）。
