# RetroMail 3.5：iPhone OS 3 风格的邮件客户端

## 3.5 更新

- **实时收信**：应用打开时用 IMAP IDLE 和服务器保持连接，新邮件一到就出现在列表里；另外每 1 / 2 / 5 / 15 分钟自动检查一次（设置 → 收取新邮件）。从后台切回来会马上检查。
- **新邮件通知**：默认开启。通知标题是发件人、副标题是主题、正文是邮件开头几行，同一会话的通知会叠在一起；通知上可以直接“标为已读 / 归档 / 删除 / 回复”，点通知打开那封邮件。应用图标显示收件箱未读数。跟进提醒的通知上有“完成 / 1 小时后再提醒”。
- **我的回复出现在列表里**：收件箱等文件夹的会话会把“已发送”里你的回复并进来（像 Gmail / Outlook），会话行显示“我”和回复箭头，按最后一封（包括你的回复）的时间排序。
- **移动 / 归档 / 删除立即生效**：邮件马上出现在目标文件夹里（用服务器返回的新 UID），底部弹出“已移到 … · 撤销”。新增“归档”按钮：会话页底部、列表左滑、编辑模式。
- **iCloud 存档修复**：文件选择器改为直接弹出，一打开就在 iCloud 云盘；进入要用的文件夹后点右上角“打开”即可，选好后会立即试写确认。另外新增“导出压缩包”：把缓存的邮件打成 .zip 存到 iCloud 云盘，可选择存好后删除本机副本。
- **ChatGPT 订阅登录**：AI 设置里新增“ChatGPT 订阅（账号登录）”，用 OpenAI 官方的 “Sign in with ChatGPT” 登录后直接使用你的 Plus / Pro 订阅额度，不需要 API Key，可选择模型。


## 3.4 更新

- **邮箱文件夹管理**：首页每个账户右侧有“编辑”。进入编辑后点任意邮箱可以改名、移动到别的文件夹下、换图标、删除；最下面有“新建邮箱”。长按邮箱按钮也能“编辑邮箱 / 新建子邮箱”。新建、改名、删除直接在服务器上进行。
- **更多邮箱图标**：图标库扩充到 50 多个（彩色文件夹、带标志的文件夹、日历、联系人、文档、表格、工程、地球、服务器……），全部来自 Oxygen / Tango 图标集，可在编辑页里挑选，也可以恢复“自动”。
- **跟进事项**：邮件卡片“更多”里有“跟进…”和“加旗标”。可以设置旗标颜色、优先级、提醒时间（到时推送通知）、截止日期、备注，还能一键加到 iOS“提醒事项”。首页顶部的“跟进事项”汇总所有事项，按“已逾期 / 今天 / 明天 / 7 天内 / 以后”分组，可勾选完成，点一下打开邮件。“导入旗标”可以把在电脑或网页上加了旗标的邮件也拿进来。列表和会话里会显示旗标、截止时间和备注。
- **离线缓存转存到 iCloud**：设置 → 存储 → 离线缓存与 iCloud 存档。选一个 iCloud 云盘里的文件夹，就可以把下载过的邮件原文和附件转存过去，腾出手机空间；可以只转存 7 / 30 / 90 天前的，也可以设置自动转存。转存过的邮件照样能打开（先从存档读取，读不到再从服务器下载）。
- **列表预览加载更快**：进入文件夹时，缓存里的邮件立刻开始补预览，不再等列表刷新完；屏幕上最上面的十几封走已经连好的快速连接，小批量先出结果，其余在另一条连接上补。
- **AI 助手新增两种方式**：
  - **用我的订阅（AI App）**：在 ChatGPT、Claude、Gemini、DeepSeek、豆包、Kimi 的官方 App 里用你自己的订阅生成，回答复制后回来点“粘贴回答”即可，不需要 API Key。
  - **Apple 本机 AI**：iOS 26 + 支持 Apple 智能的 iPhone 上可以用，免费、离线，邮件不出手机。
  - 写信时还可以用 iOS 18.2 的“写作工具”（如果在系统设置里登录了 ChatGPT，用的就是你的 ChatGPT 账号）。

> 关于“用订阅”：ChatGPT、Claude 等服务商不允许第三方应用拿订阅账号的登录令牌直接调用模型（有封号风险），所以 RetroMail 不保存、不接触你的账号或令牌，而是交给你手机上已登录的官方 App 去生成。


## 3.3 更新

- **会话里每封邮件是一张独立卡片**：条纹背景上的圆角卡片，标题条带发件人彩色首字母徽章、名字、日期和“发给 我 等 3 人”；最新一封用蓝色描边。**点一下标题条就折叠 / 展开**，折叠后只显示两行摘要。会话顶部有“全部展开 / 全部折叠”。“另外 N 封邮件”改成叠起来的卡片。
- 每封邮件底部有操作条：回复、全部回复、转发、缩放、更多（更多里有全屏查看、标为未读、删除这封邮件）。
- **主页改为长条按钮**：每个邮箱一个整行的光泽长条按钮（图标＋名称＋未读数），按下变蓝；子文件夹缩进。图标换成开源图标库 Tango / Oxygen 的彩色图标，不再用系统图标。设置 → 阅读 里可以关掉图标，只显示文字。
- **签名可以自定义了**：账户设置 → 签名，进入签名编辑页，可以设字体、字号、颜色、加粗、链接、插入 Logo 图片，也可以把别处复制来的签名直接粘贴进来。可以分别设置“新邮件”和“回复和转发”是否自动加签名。写信时切换发件账户，签名会跟着换。
- 修复：宽邮件缩小显示后下方留一大片空白；列表和会话里的日期被截断（如 “Mor…”）；写信时签名用的是旧账户设置。

图标来源：[Tango Desktop Project](http://tango.freedesktop.org/)（公有领域 CC0）、[KDE Oxygen Icons](https://github.com/KDE/oxygen-icons)（LGPL）。

## 3.2 更新

- 邮箱列表改成 iPhone OS 3 设置页那样的分组按钮：条纹背景、白色圆角分组、彩色光泽小图标、按下变蓝；子文件夹缩进显示。
- 缩放查看：宽邮件会提示“已缩小显示 · 点此放大查看”；每封邮件右上角有“⤢”全屏按钮。全屏页可以双指缩放，底部有缩小 / 适合宽度 / 实际大小 / 放大。夜间模式下正文底色和界面一致。


## 3.1 更新

- **新图标**。
- **打开邮件不再卡住界面**：邮件解析、摘要、引用识别、页面生成全部在后台一次算好，界面只显示结果；下载时可以照常滚动、返回。
- **显示优化**：导航栏标题会自动避开左右按钮，不再重叠；列表预览改在空闲连接上加载，打开邮件时不会被中断，回来会继续；预览里去掉了乱码、`<mailto:…>`、`[cid:…]` 等杂项；自己的地址显示为“我”；会话页更紧凑，超过 4 封时中间的旧邮件折叠成“另外 N 封邮件”。
- **附件全面支持**：
  - `.eml`（转发的邮件）在应用内直接打开，能看正文、看里面的附件，还能回复/转发；文件名改用邮件主题。
  - `.ics`（会议邀请）显示时间、地点、组织者、参加者，可“添加到日历”，可直接“接受 / 暂定 / 拒绝”并把回复发给组织者（Outlook 能识别）。正文上方也会显示邀请卡片。支持 Outlook 的 Windows 时区名。
  - `winmail.dat`（Outlook 的 TNEF 格式）会自动解包出里面真正的附件。
  - 每个附件右侧“⋯”：预览、存储到“文件”、共享 / 用其他 App 打开；多个附件可“全部存储”。

- 蓝灰渐变导航栏和底部工具栏；尖角“返回”按钮；蓝色“完成/发送”按钮；全部使用 Helvetica 字体。

- **邮件列表**：顶部搜索栏；未读邮件有蓝色玻璃圆点；日期用蓝色；每封邮件显示两行灰色正文预览（后台只取每封邮件开头 1.5 KB）；底部“载入更多邮件 / 共 N 封邮件，X 封未读”。“编辑”模式下左侧出现圆圈勾选，底部有红色“删除”和“移动”“标记”。

- 夜间模式使用 iPhone OS 3 的黑色栏样式和深色表格。

### 写信功能（功能区 5 个标签）

- **开始**：撤销、重做；加粗、倾斜、下划线、删除线、上标、下标；字体（含宋体、黑体、楷体、仿宋、微软雅黑、Calibri、Arial、Times New Roman 等）；字号 8–72 磅、增大、缩小；字体颜色（Office 主题色板＋标准色＋自定义）；突出显示（填充色）；格式刷；清除格式。
- **段落**：项目符号（● ○ ■ ◆ ➤ ✓ ★ – → ☐ ❖ •）；编号（1. / 01. / a. / A. / i. / I. / 一、 / (1)）；缩进、减少缩进；左对齐、居中、右对齐、两端对齐；行距 1.0–3.0；段后间距；样式（正文、标题 1–4、引用、代码）；引用块。
- **插入**：超链接（新建、编辑、删除，网址和邮箱都可以）；正文内嵌图片（自动压缩）；附件（照片或文件）；表格；待办清单；分隔线；日期时间；签名；特殊符号。
- **表格**：插入表格时可设行列数、标题行、是否占满宽度、边框样式。之后可以在上下插行、左右插列，删除行、删除列，向右合并单元格，设置单元格底纹，切换无边框、细边框、粗边框，切换占满宽度或自动宽度，删除表格。
- **工具**：AI 写作、查找替换、更改大小写、重要性（高/低）、请求已读回执、存草稿。

发出的邮件同时包含 HTML 版和纯文本版。内嵌图片以标准的 `cid:` 方式附带，Outlook、Foxmail、网页邮箱都能正常显示。回复和转发时会带上 Outlook 风格的原邮件信息（发件人、发送时间、收件人、主题）。

> 写信区域在夜间模式下也保持白底，这样所见即所得，和对方收到的效果一致。

### AI 设置

在 **控制面板 → AI 助手 → 设置…** 里填写：

- **接口类型**：选“OpenAI 兼容”或“Anthropic”。
- **服务地址**和**模型**：可以直接套用预设（OpenAI、Claude、DeepSeek、通义千问、Kimi、智谱、OpenRouter）。
- **API Key**：你在服务商那里申请的密钥。

如果你用的是国内中转服务（OpenAI 兼容格式），选“OpenAI 兼容”，填入中转地址和 Key 即可。

AI 功能使用你自己的 API Key，按用量计费。ChatGPT、Claude 等**网页订阅**的登录令牌不能在第三方应用里使用：服务商条款不允许，强行使用有封号风险。

## 已知限制

- 不支持 Microsoft 365 / Exchange Online 的 OAuth 登录。
- 新邮件提醒依靠 iOS 后台刷新，不是实时推送。
- 会话视图会到“收件箱”和“已发送”里按主题查找相关邮件，最多显示 40 封。
- 更改界面语言后会回到主页（界面需要重新载入）。

## 项目结构

```
project.yml                  XcodeGen 工程描述
.github/workflows/build.yml  云端编译，打包未签名 ipa
RetroMail/App                入口、外观/语言设置、配色
RetroMail/Core               TLS 套接字、IMAP、SMTP、MIME 解析与生成
RetroMail/Models             账户、钥匙串、缓存、会话分组、后台刷新
RetroMail/Editor             富文本编辑器（WebKit）、功能区、AI
RetroMail/UI                 复古组件、主页、列表、会话、写信、设置
```

没有任何第三方依赖。
